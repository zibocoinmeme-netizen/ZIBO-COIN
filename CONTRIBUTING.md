# Contributing to ZIBO COIN

ZIBO belongs to the community.

Contributions that help build the character, memes, culture, documentation, and open-source foundation are welcome.

## Good contributions

- Original ZIBO memes and artwork
- Lore and creative ideas
- Documentation improvements
- Website concepts and implementation
- Repository organization and tooling
- Community-oriented ideas that fit the ZIBO identity

## Principles

1. Keep ZIBO original.
2. Do not copy existing meme characters or branding.
3. Do not invent project facts, partnerships, listings, investors, statistics, or financial claims.
4. Clearly label proposed or unfinished information as planned, under development, or to be announced.
5. Never submit private keys, seed phrases, passwords, or other secrets.
6. Keep changes focused, readable, and easy to maintain.

## Pull requests

Please explain what changed and why. Documentation and creative contributions should preserve the project's distinction between current facts and future plans.

For technical changes, include appropriate validation or testing information.

# ZIBO Project Architecture

## Purpose

This repository is the open-source foundation for ZIBO COIN and the wider ZIBO meme culture project.

## Current architecture

At the current stage, the repository is intentionally documentation-first. It provides a canonical place for project identity, lore, brand guidance, community principles, roadmap, and security practices.

```text
ZIBO Character
      ↓
Original Content
      ↓
Meme Culture
      ↓
Community
      ↓
Open-Source Project
      ↓
Future Infrastructure
      ↓
Future ZIBO COIN
```

## Future infrastructure

A future implementation may include a website and token-related technical infrastructure. Those components must be added only when actually developed and should be clearly separated from planned concepts.

No smart contract is represented as deployed by this repository.

## Planned website

The future website should provide:

- ZIBO identity and hero section
- Lore
- Meme culture
- Community
- Roadmap
- Token — Coming Later
- GitHub
- X/Twitter

The visual direction is modern internet/meme culture: green, orange, dark backgrounds, space/Earth imagery, digital elements, large typography, and strong ZIBO character presence.

## Source-of-truth rule

Repository documentation should distinguish clearly between current facts, planned concepts, and deployed/verifiable technical facts. When a planned component becomes real, documentation should be updated with verifiable evidence rather than assumptions.

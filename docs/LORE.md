# ZIBO Lore

## The beginning

ZIBO appeared on the internet as a creature that did not want to follow meme rules.

ZIBO is not perfect.
ZIBO is not serious.
ZIBO does not ask for permission.

ZIBO exists to transform simple ideas into meme culture.

ZIBO belongs to the community.

## The core idea

ZIBO is an original internet meme character with its own personality, visual identity, language, lore, and culture.

ZIBO is not another Shiba Inu, Pepe, Dogecoin, or existing meme character.

The core phrase is:

> ZIBO is ZIBO.

## The sequence

Character → Meme → Culture → Community → Movement → ZIBO COIN

The character comes first. The meme comes second. The culture grows from the community. The token is a future component, not the current center of the project.

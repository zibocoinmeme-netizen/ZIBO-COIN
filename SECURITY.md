# Security Policy

## Current status

ZIBO COIN has not been launched. There is currently no deployed ZIBO token or production smart contract in this repository.

## Rules

- Never commit private keys, seed phrases, recovery phrases, passwords, or secrets.
- Public blockchain addresses may be documented when they are intentionally designated as public project wallets.
- Do not treat a wallet address as proof of token deployment or funding.
- Smart contracts must be independently reviewed before any future deployment.
- Deployment details must only be published after an actual, verifiable on-chain deployment.
- Planned token parameters and draft tokenomics must never be represented as deployed facts.

## Reporting a vulnerability

If you identify a security issue in this repository, do not publish sensitive exploit details in a public issue. Contact the project maintainers through an official project channel and provide enough information to reproduce and assess the issue safely.

## Scope

This policy covers the open-source repository and future project infrastructure documented here. It does not make claims about the security of third-party services, wallets, exchanges, blockchains, or applications.
